# Lab1Web

Repository Praktikum 1 - HTML Dasar.

## Isi Praktikum

Praktikum ini membahas:
- Struktur dasar HTML
- Heading
- Paragraf
- Pemformatan teks
- Hyperlink
- Gambar
- Unordered list
- Ordered list
- Komentar HTML
- Navigasi antarhalaman

## Struktur Folder

```text
Lab1Web/
├── index.html
├── halaman2.html
├── README.md
└── images/
    └── profil.jpg
```

## Cara Menjalankan

Buka file `index.html` menggunakan browser.

## GitHub Pages

Setelah repository di-upload ke GitHub:
1. Buka **Settings**.
2. Pilih **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main`.
5. Pilih folder `/ (root)`.
6. Klik **Save**.

Website dapat diakses melalui:

`https://USERNAME.github.io/Lab1Web/`

Ganti `USERNAME` dengan username GitHub masing-masing.

## Catatan

Ganti `Nama Mahasiswa` pada `index.html` dengan nama mahasiswa yang sebenarnya.
Ganti file `images/profil.jpg` dengan foto yang digunakan untuk praktikum.
